# 🔗 Synthesis Echo

## Purpose

The **Synthesis Echo** combines multiple sources, perspectives, or data points into a coherent and structured synthesis. It identifies patterns, resolves contradictions, and creates unified understanding while maintaining traceability to original sources.

## When to Use

- Multiple documents or sources need to be combined
- Conflicting expert opinions require integration
- Research from different domains needs synthesis
- Strategic decisions require input from diverse stakeholders
- Data from multiple sources needs unified analysis

## Key Features

- **Source Traceability**: Maintains connection to original sources
- **Contradiction Resolution**: Actively addresses conflicting information
- **Pattern Recognition**: Identifies themes across diverse inputs
- **Structured Output**: Produces organized, actionable synthesis

## Example Scenarios

### Research Synthesis

```yaml
Sources: Academic papers, industry reports, expert interviews
Output: Literature review with key findings and research gaps
```

### Strategic Decision Making

```yaml
Sources: Market analysis, financial projections, stakeholder feedback
Output: Strategic recommendation with supporting rationale
```

### Product Requirements

```yaml
Sources: User research, technical constraints, business requirements
Output: Unified product specification with priority matrix
```

## Execution Modes

### Simplified Version (`synthesis-integrative.yaml`)

- Quick synthesis for straightforward integration tasks
- Basic pattern recognition and organization
- Suitable for ChatGPT or similar AI interfaces

### PRS Version (`synthesis-integrative.prs.yaml`)

- Full validation and traceability
- Detailed contradiction analysis and resolution
- Structured output with comprehensive documentation
- Retry logic for complex synthesis challenges

## Integration with Other Echoes

- **🧪 Evaluation**: Assess source quality before synthesis
- **🔍 Diagnostic**: Analyze why sources contradict each other
- **🧭 Planning**: Structure complex multi-source synthesis projects
- **📊 Prioritization**: Rank sources by reliability or relevance

## Tips for Effective Use

1. **Source Quality**: Use Evaluation Echo first to assess source reliability
2. **Clear Framework**: Define integration criteria before starting synthesis
3. **Contradiction Handling**: Don't ignore conflicts—analyze and resolve them
4. **Traceability**: Always maintain links back to original sources
5. **Iterative Refinement**: Use coherence checks to improve synthesis quality
